# KartVantage Final Prototype - 20-sep-2026

Interactive UI/UX review prototype for the KartVantage Shopify app ecosystem.

This prototype covers the merchant, admin, CRM, and support experiences, including responsive layouts, purchase-rule management, the cart drawer, and live storefront previews.

## Important

- This is a design and interaction prototype, not production application code.
- All merchants, products, rules, tickets, and metrics are sample data.
- No Shopify store or customer data is changed.
